## Decisiones de diseño (para quien siga)
1. **No compilar packwiz**: los archivos de packwiz (`pack.toml`, `index.toml`, `mods/*.pw.toml` con name/filename/side/[download] url+hash-format sha1+hash/[update.modrinth]) se generan desde Python con los datos de Modrinth; sólo `packwiz-installer-bootstrap.jar` (releases de GitHub, `packwiz/packwiz-installer-bootstrap`) hace falta, y sirve también para probar el formato corriéndolo contra una carpeta temporal (no toca instancias).
2. **Base BMC5**: hashear los 267 jars de `%APPDATA%\PrismLauncher\instances\Better MC 5 (1.21.1)\.minecraft\mods` (sólo lectura) y `POST /v2/version_files {hashes, algorithm: sha1}` → versión exacta de cada uno (project_id, files[].url/hashes, dependencies). Así el pack queda pinneado a lo ya verificado. Los nuevos: `/project/{slug}/version?loaders=["neoforge"]&game_versions=["1.21.1"]` (última release) + cierre de dependencias `required`.
3. Side: de `client_side/server_side` de Modrinth; el server de bmc5 sólo necesitó sacar 2 jars de cliente: `BetterGrassify-1.6.1+neoforge.1.21.1.jar` y `distraction_free_recipes-neoforge-1.2.1-1.21.1.jar` → marcarlos `side=client`. Ojo: `bmc5-arreglo.log` terminó en `TimeoutExpired` de `p.wait(120)` DESPUÉS del Done (el stop tardó en guardar): el server sí arrancó; subir ese timeout en `server_sin_mods_de_cliente.py`.
4. Shaders/resource packs van al pack como `.pw.toml` en `shaderpacks/` y `resourcepacks/` con side=client; el shader por defecto de cada combo se fija con `config/iris.properties` (`shaderPack=...`) marcado `preserve = true` (se escribe la 1.ª vez, no pisa lo que el jugador cambie).
5. Combos propuestos (6, dentro de L1-08 4-8): BMC5 sin castigos · Aventura minecraftera · Dimensiones y jefes · Con mecanismos · Liviana · **Espacio** (= Aventura + espacio; la aventura de base anda mejor que BMC5 entero: menos choques y ~6 GB).
6. Lista de castigos (L1-10): tough-as-nails, cold-sweat, thermoo, frostiful, scorchful + sed. Mirar también por dependencia (un mod que arrastre Thermoo).
7. Probar el servidor de prueba/sabotajes con un lanzador intercambiable (stub que imprime Done / revienta) para testear la lógica "sólo publica si llega al Done" sin arrancar Minecraft; la prueba real con el server queda para cuando Fran diga que terminaron de jugar.

## Combo Espacio — candidatos medidos en Modrinth (1.21.1 + NeoForge, API con filtros, 2026-11-24)
Descargas entre paréntesis. cl/sv = client_side/server_side.
- **Ad Astra** `ad-astra` (6,08 M, req/req): el estándar: cohetes, planetas (Luna, Marte, Venus, Mercurio, Glacio), estaciones. Anda en NeoForge 1.21.1.
- Complementos de Ad Astra: `ad-astra-more-structures` (65 k, estructuras y jefes en los planetas), `dungeon-and-village-ad-astra` (14,6 k, dungeons y pueblos), `simple-structure-ad-astra` (12 k), `ad-astra-asteroid-belt` (1,6 k), `ad-astra-orbit` (Orbit+, 0,8 k, asteroides en órbita), `ad-astra-recycling` (3,4 k, desarmar cohetes), `ad-astra-giselle-addon` (2,56 M, comodidades: trajes, tanques; conviene), `per-spatium` (57 k, pide Stellaris además).
- **Stellaris** `stellaris` (205 k, req/req): otro mod espacial «de nueva generación», alternativa a Ad Astra (no juntar los dos sin probar). Addons: `stellaris-extra`, `create-stellaris`.
- **Create: Northstar / Create Aeronautics** (`create-northstar-structures`, `create-aerostar`, `northstar-aeronautics-compat`, `creating-space` 79 k, `create-rockets` 34 k, `create-propulsed`): cohetes y planetas con Create. Más complejos: sólo para «mecanismos + espacio», no el base.
- Cielo/astronomía: `stellarview` (Stellar View, 256 k, cl req / sv uns: cielo estrellado realista) + `adastra-stellarview-compatibility` (cielo propio de cada planeta de Ad Astra) + `stellar-view-mixin-renderer`; `caelum` (316 k, estrellas y órbitas keplerianas reales, client); `celestria` (262 k, estrellas fugaces y eventos); `enhanced-celestials` (2,56 M: eclipses/lunas de sangre/cosecha: las lunas de sangre son un «castigo» suave, dejar opcional); `cosmicore` (12,5 k, meteoritos y piedras espaciales); `starstruck-the_letter_a` (0,5 k, constelaciones con catalejo); `exposure-space` (35 k, astrofotografía, pide Exposure); `stellara` (6,6 k, skyboxes por bioma).
- Dimensiones: `nullscape`, `stellarity` (End rehecho; ya hay mods de End en BMC5: elegir uno).
- Sin 1.21.1/NeoForge o sin medir: Galacticraft 5 (no apareció), Twilight Forest (no está en Modrinth: buscar en CurseForge).
- **Conclusión propuesta**: Espacio = Aventura + Ad Astra + Giselle + More Structures + Dungeons&Villages Ad Astra + Asteroid Belt + Recycling + Stellar View + compat Ad Astra/StellarView + Celestria + Cosmicore (+ Caelum opcional).
